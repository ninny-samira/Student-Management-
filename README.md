## Project Description

The Student Record Management System is a simple single-page website developed to manage student information easily.

Users can add, view, search, update, and delete student records. The website also displays the total number of students and average CGPA.

## Technologies Used

- **HTML** – Website structure
- **MySQL** – Database design and SQL operations
- **GitHub Pages** – Website hosting

## Features

1. Add new student records
2. View all students
3. Search students by ID or name
4. Update student information
5. Delete student records
6. Display total students and average CGPA
7. Filter students by department
8. Sort students by CGPA

## Student Information

Each student record contains:

- Student ID
- Student Name
- Department
- Semester
- CGPA

## Database Information

**Database Name:** `student_management`

**Table Name:** `students`

The MySQL database was created using SQL commands including `CREATE`, `INSERT`, `SELECT`, `UPDATE`, and `DELETE`.

**Note:** The GitHub Pages website uses JavaScript and browser localStorage to manage records. It does not connect directly to the MySQL database.
